# yamatoLLM

Japanese-specialized LLM based on llm-jp/llm-jp-4-8b-base.

## Architecture

3-layer architecture inspired by Kojiki mythology:

- **天照層 (Amaterasu)** — Language processing (岩戸隠れアーキテクチャ)
- **月読層 (Tsukuyomi)** — Code generation
- **須佐之男層 (Susanoo)** — Governance
