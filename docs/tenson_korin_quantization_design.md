# 天孫降臨量子化設計書

> **副題**: 高天原（FP16）から葦原中国（INT4）への降臨プロトコル
>
> **位置づけ**: yamatoLLM の推論最適化層 — RTX 3060 (12GB) での動作を実現する

---

## 神話マッピング

### 天孫降臨 = 量子化

高天原（FP32/FP16の高精度世界）から葦原中国（量子化された地上の世界）に降りる。
天上の存在がそのまま地上に降りたら重すぎて存在できない。
だから「地上で動ける姿」に変わる必要がある。

```
高天原 (FP16)                    葦原中国 (INT4)
  llm-jp-4-8b-base                      yamatoLLM 推論版
  ~18GB VRAM                       ~5GB VRAM
  A100/H100                        RTX 3060
       │                               ▲
       │         天孫降臨               │
       └──── 量子化パイプライン ────────┘
```

### 三種の神器 = 量子化の3要素

| 神器 | 量子化要素 | 役割 |
|------|----------|------|
| 八咫鏡 (Yata-no-Kagami) | キャリブレーション | 自分を正確に映す → 量子化前に重みの分布を正確に測定する |
| 草薙剣 (Kusanagi-no-Tsurugi) | プルーニング | 不要なものを斬り落とす → 重要度の低い重みを除去する |
| 八尺瓊勾玉 (Yasakani-no-Magatama) | 量子化そのもの | 連続的な値を離散的な玉に変換 → FP16をINT4に丸める |

### 随伴神 = パイプラインの各ステップ

| 随伴神 | 神話での役割 | 量子化での役割 |
|--------|-----------|--------------|
| 天児屋命 (Amenokoyane) | 祝詞（神の言葉を奏上） | スケーリングファクタの計算（神の言葉を地上の言葉に翻訳する比率） |
| 太玉命 (Futodama) | 捧げ物を持つ | アクティベーション統計の収集（キャリブレーションデータを捧げる） |
| 天宇受売命 (Amenouzume) | 舞（状況に応じて踊る） | 動的量子化（状況に応じて表現を変える） |

## 三種の神器の保護規則

量子化において「斬ってはいけないもの」がある。

```
草薙剣（プルーニング）の禁忌:

  斬れるもの:
    ✓ Qwen Transformer の冗長なヘッド/チャネル
    ✓ SwiGLU FFN の低重要度ニューロン
    ✓ Embedding の低頻度トークン重み

  斬ってはいけないもの:
    ✗ カスタムヘッド全体（intent_router, confidence, kotoyosashi）
    ✗ LoRA アダプタの重み（yamatoLLM 固有の学習結果）
    ✗ 最終層の LM Head（出力品質に直結）
    ✗ RoPE の周波数パラメータ
```
